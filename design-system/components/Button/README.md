# Button

Botões do site e das peças: mono em CAIXA ALTA, canto reto com chanfro e um traço claro no topo.

- Primário: `.ad-btn.ad-btn-primary`, fundo `action` (azul do carro) e texto `on-action`, 13px/700 com tracking 1.2px, padding `space-4` × `space-6`, chanfro `chamfer-sm`.
- Sinal: `.ad-btn.ad-btn-signal`, fundo `signal` e texto `on-signal`. É o CTA de engajamento ("Comenta AGENTE"); no máximo um por tela, e nunca junto com outro primário.
- Secundário: `.ad-btn.ad-btn-ghost`, painel com borda `line` e texto `brand-bright`.
- Nav: `.ad-nav` com itens ◈ em `ink-faint`; o item ativo (`.on`) leva borda `line-strong` e texto `brand-bright`.
- Rótulos são verbos curtos ("Ver projetos", "Me chama"). Seta → no fim quando leva para fora.
- Foco: contorno 2px `signal`, offset 3px.
