# HighlightCover

Capas dos destaques do perfil: fundo `bg` com grid, ícone de traço em `signal` e anel `brand`.

- Exporte o miolo 1080×1080 com o ícone centralizado ocupando cerca de 30% da largura. O anel do preview é só referência, porque o Instagram desenha o dele.
- Ícones de traço 1.75px com pontas retas (square/miter), combinando com os cantos retos da v2. Todos no mesmo peso, sem emoji. Os ícones do preview são genéricos: troque por um set de traço consistente (ex.: Lucide) quando for produzir.
- Destaques sugeridos, um por pilar mais serviço: IA, Jornada, Mentalidade, Humor, Serviços.
