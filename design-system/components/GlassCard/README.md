# GlassCard (painel)

Painel cobalto chanfrado: é o container padrão do Modo Tech. O nome continua GlassCard; na v2 ele é um painel, não vidro.

- `.ad-card`: fundo `panel` sobre `bg`, borda 1px `line`, cantos retos com chanfro `chamfer-md`, traço `brand` de 2px no topo esquerdo, padding `space-6`.
- Número opcional `.ad-num` (01, 02…) no canto superior direito, em `line-strong`; serve para listas e séries.
- Rótulo `.ad-label` (◈ em mono), título `card-title` (Geist 700) em `ink-strong` e corpo em mono `ink-soft`.
- Tags de stack: `.ad-tag`. Meta (NODE · MODE · STATUS): `.ad-meta`.
- Nas peças IG use `.ad-ig-card` (a mesma receita escalada, chanfro `ig-chamfer`).
- Não coloque um painel dentro de outro. Sem borda lateral colorida.
