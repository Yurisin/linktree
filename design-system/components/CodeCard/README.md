# CodeCard

O "objeto `yuri`", assinatura técnica da marca: um painel de código com halo `glow`.

- `.ad-code`: `mono` 13px/21px, padding `space-5`, fundo `panel`, borda `line`, chanfro `chamfer-md`, sombra `glow`.
- Cores de sintaxe: comentário `code-comment`, `const` em `brand`, nome em `ink-strong`, chaves em `code-prop` (cobalto claro), strings em `code-string` (verde de sinal), booleanos em `code-bool` (amarelo) e pontuação em `ink-faint`.
- Conteúdo: sempre um fato real resumido como objeto ou config curta, com até 7 linhas. Ex.: `const agente = { canal: "whatsapp", humanizado: true }`.
- Num slide do Instagram use `.ad-ig-card.ad-ig-code` (30px/48px).
- A fonte é Geist Mono (Google Fonts), a mesma em todas as máquinas.
