# Origem

Cópia do design system **Alemão Dev v2 (híbrido cobalto)**, exportada em 2026-10-21 do artifact
https://claude.ai/artifact/WDuesXajrQnibPfjpg9EoU (versão 1792546748-cfdc, última mudança 2026-10-21).

- `README.md`: regras de marca, cor, tipografia, forma e voz.
- `tokens.json`: tokens (cor, tipo, espaço, raio, sombra, degradê). O `bundle.css` usa esses tokens como
  variáveis CSS (`var(--bg)`, `var(--brand)`, `var(--font-mono)`…): gere as variáveis a partir daqui.
- `components/bundle.css`: classes de componente (prefixo `ad-`).
- `components/<Nome>/README.md`: uso de cada componente.

Fonte da verdade é o artifact. Quando o Yuri mudar o design system, exporte de novo e substitua esta pasta.
Avatar oficial: foto do mirante (asset do artifact, grupo Avatar).
